⚙ AI 接口配置

Key 仅保存在本机 LocalStorage，不会上传到任何服务器。直接在浏览器使用 Key 会有风险 —— 仅在你能接受时使用。
OpenAI 默认填写 https://api.openai.com；自建/代理填入对应地址。若使用 Google/其它，请填写对应 Base URL。
例如填写 gpt-4o-mini。若不填写，将使用 gpt-4o-mini 作为默认。
说明：浏览器直接调用第三方 AI 接口可能遇到 CORS 或 Key 泄露风险。若出现 CORS/401，请使用后端代理或确认服务支持浏览器调用。

💾 数据备份与恢复

所有打卡/账本存在本机浏览器。换设备或清缓存会丢，请定期导出备份到手机/电脑。
